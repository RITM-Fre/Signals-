# 🛰️ Signal Console

> همه‌ی ابزارهای رمزنگاری، کدگذاری و هش — توی یه فایل HTML، بدون سرور، بدون آپلود، کاملاً محلی.

Signal Console یک کنسول جامع برای **Encode / Decode / Encrypt / Decrypt / Hash** است که تمام عملیات را مستقیماً در مرورگر کاربر اجرا می‌کند. هیچ داده‌ای به هیچ سروری ارسال نمی‌شود، هیچ تبلیغی نمایش داده نمی‌شود، و پس از اولین بارگذاری حتی به اینترنت هم نیازی ندارد.

---

## ✨ ویژگی‌های کلی

- 🖥️ **رابط کاربری مدرن** با پس‌زمینه‌ی سه‌بعدی تعاملی (Three.js)
- 📴 **کاملاً آفلاین** — بعد از اولین لود، بدون اینترنت کار می‌کند
- 🔒 **حریم خصوصی مطلق** — هیچ داده‌ای از دستگاه خارج نمی‌شود
- 📱 **ریسپانسیو** — روی موبایل، تبلت و دسکتاپ
- 📋 **کپی یک‌کلیکی** با fallback برای همه‌ی مرورگرها و `file://`
- 🇮🇷 **پشتیبانی از فارسی** در بخش Morse با تبدیل خودکار به فینگلیش

## 🧰 ابزارها و الگوریتم‌ها

### 📦 کدگذارها (Encoders)

| ابزار | توضیح |
|---|---|
| Base64 | کدگذاری/کدگشایی متن و فایل با پشتیبانی تصویر |
| Hex | تبدیل متن به هگز و برعکس |
| Binary | تبدیل متن به رشته‌ی باینری ۸ بیتی |
| URL Encoding | کدگذاری کاراکترهای خاص URL |
| HTML Entity | تبدیل کاراکترهای خاص به entity |
| Unicode Escapes | تبدیل به `\uXXXX` و برعکس |

### 📡 Morse

- تبدیل متن به کد مورس و برعکس
- **پشتیبانی از فارسی** — متن فارسی به‌طور خودکار به فینگلیش تبدیل و سپس به مورس ترجمه می‌شود
- پخش صوتی با فرکانس ۶۲۰ هرتز و لامپ چشمک‌زن
- تشخیص خودکار زبان (فینگلیش / انگلیسی / فارسی)

### 🔐 رمزهای کلاسیک

| رمز | ویژگی |
|---|---|
| Caesar | شیفت ۱ تا ۲۵ |
| ROT13 | شیفت ثابت ۱۳ |
| Vigenère | کلید متنی |
| Atbash | جایگزینی معکوس الفبا |
| Affine | ضرایب `a` و `b` (a باید coprime با ۲۶ باشد) |
| Playfair | ماتریس ۵×۵ با کلید |

### ⚡ رمزهای مدرن

| الگوریتم | توضیح |
|---|---|
| XOR | رمز XOR با کلید متنی — خروجی hex |
| AES | AES استاندارد با CryptoJS — کلید passphrase |
| TripleDES | 3DES با CryptoJS |
| ChaCha20 | پیاده‌سازی سبک با PRF مبتنی بر SHA-256 |

### 🔑 رمزنگاری نامتقارن

| الگوریتم | توضیح |
|---|---|
| RSA | تولید کلید ۲۰۴۸ بیتی RSA-OAEP، رمزگذاری و رمزگشایی |
| ECC | تولید کلید ECDH روی منحنی P-256 |
| Diffie-Hellman | تبادل کلید و استخراج shared secret |

### #️⃣ هش

| الگوریتم | خروجی |
|---|---|
| MD5 | 128-bit |
| SHA-1 | 160-bit |
| SHA-256 | 256-bit |
| SHA-384 | 384-bit |
| SHA-512 | 512-bit |
| RIPEMD-160 | 160-bit |

با پشتیبانی از حالت **Compare** برای مقایسه با هش انتظاری.

### 🔒 هش رمز عبور

| الگوریتم | ویژگی |
|---|---|
| bcrypt | با salt قابل تنظیم |
| scrypt | N=16384, r=8, p=1 |
| Argon2id | iterations=3, memory=4MB |

با تولید خودکار salt و حالت **Verify** برای بررسی صحت.

### 🎁 امکانات ویژه

- **gzip Compression** — فشرده‌سازی و بازکردن با `CompressionStream`
- **Steganography** — پنهان‌کردن پیام داخل تصویر PNG با تکنیک LSB

## 🔧 روش کار

### معماری کلی

```
┌──────────────────────────────────────────┐
│            HTML (single file)            │
├──────────────────────────────────────────┤
│  Header  →  Navigation + Dropdown        │
│  Main    →  Panels (one per tool)        │
│  Footer  →  Links + Contact              │
├──────────────────────────────────────────┤
│  JS Layer:                               │
│   • Three.js       → background          │
│   • CryptoJS       → AES, TripleDES      │
│   • Web Crypto API → RSA, ECC, DH        │
│   • hash-wasm      → hashes & passwords  │
│   • Vanilla JS     → UI + all logic      │
└──────────────────────────────────────────┘
```

### جریان کار

1. **انتخاب ابزار** از هدر یا منوی کشویی
2. **انتخاب حالت** (Encode / Decode یا Encrypt / Decrypt)
3. **ورود متن/کلید** در فیلد مربوطه
4. **تبدیل لحظه‌ای** — خروجی بدون دکمه‌ی اضافه به‌روز می‌شود
5. **کپی نتیجه** با یک کلیک

### تکنیک‌های پیاده‌سازی

- **Base64:** `TextEncoder` + `btoa` (پشتیبانی UTF-8)
- **Morse:** نقشه‌ی کاراکتر به کاراکتر + دیکشنری فارسی → فینگلیش
- **AES/DES:** `CryptoJS.AES.encrypt` و `CryptoJS.TripleDES.encrypt`
- **RSA/ECC/DH:** `crypto.subtle` (Web Crypto API)
- **Hashing:** `hash-wasm` برای سرعت بالا
- **Steganography:** LSB روی کانال قرمز پیکسل‌ها با Canvas API
- **Clipboard:** fallback بین `execCommand('copy')` و `navigator.clipboard`

## 🚀 نصب و اجرا

### روش ۱ — اجرای مستقیم

```bash
# فقط فایل index.html را در مرورگر باز کن
open index.html
```

### روش ۲ — سرور محلی (اختیاری)

```bash
python3 -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

### روش ۳ — استفاده‌ی آفلاین

پس از اولین بارگذاری، تمام کتابخانه‌ها کش می‌شوند و بدون اینترنت کار می‌کند.

## ⚠️ نکات امنیتی

- این ابزار برای **یادگیری، تست و کارهای روزمره** طراحی شده است.
- برای رمزنگاری داده‌های حساس، از کتابخانه‌های استاندارد و به‌روز استفاده کنید.
- الگوریتم‌های MD5، SHA-1 و DES دیگر امن نیستند و فقط برای سازگاری یا آموزش هستند.
- ChaCha20 پیاده‌سازی‌شده، نسخه‌ی ساده‌شده است و برای کاربردهای واقعی توصیه نمی‌شود.
- Steganography در این ابزار، فقط برای آموزش است و مقاومت کمی در برابر تحلیل دارد.
